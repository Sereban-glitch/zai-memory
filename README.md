и не коммитить в репозитории владельца; прод не трогать; секреты не выносить;
факты не выдумывать. При предложении слабой модели — закрыть крестиком, подождать
и отправить тот же промпт. При обрыве хода — ровно одно продолжение, сверяясь
с `HANDOFF.md`. Пока агент работает — не писать ему и не нажимать кнопку прерывания.
